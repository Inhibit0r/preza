# preza для Codex

Вызовите `$preza:preza` из папки проекта и дайте тему, условие или лекции. Ведущей остаётся выбранная сессия Codex. Бриф уточняет недостающие длительность или число страниц, уровень и необходимость речи. Предыдущие колоды и выступления помогают восстановить стиль, аудиторию и формат. Речь по умолчанию единая.

## Сценарий

[Основной навык](skills/preza/SKILL.md) управляет раскадровкой, обликом, нативной сборкой и проверкой. Дизайн новой темы выбирает агент. Серия использует свой DESIGN.md, спецификацию или принятую работу. [House rules](skills/deck-house-rules/SKILL.md) содержат критерии первой выдачи и пополняемые антипаттерны. [Orca](skills/preza/references/hosts.md) регистрирует работников. Их модели и глубина настраиваются в [профилях](skills/preza/references/worker-profiles.json). Папки сдачи, защита ручных правок и именование описаны в [регламенте хранения](skills/preza/references/layout.md).

| Уровень | Результат |
|---|---|
| Срочный | Quick Generate, одно направление, проверка фактов и рендеров, ключевой кадр по необходимости |
| Обычный | Авторский дизайн, ImageGen, редактируемая инфографика, независимый визуальный разбор всех содержательных слайдов |
| Усиленный | Предварительная критика сложных схем и кадров, повторный рендер и проверка |
| Полный дизайн | Референсы, три направления с эскизами и отдельная финальная визуальная инспекция |

`$preza:animate` добавляет движение к исходному проекту PPT Master. Без анимации сдаётся обычная статическая колода. Для выбранного движения предусмотрен вариант без эффектов. Локальные решения и принятое владельцем оформление накапливаются в [памяти презентаций](skills/preza/references/memory.md).

## Установка и сборочное окружение

Внешняя установка использует Codex marketplace этого репозитория. Выбирайте ref нужного выпуска. В переносимом стеке используйте его штатный установщик. Кэш установленной копии обслуживает Codex. После установки начните новый сеанс и вызовите `$preza:setup`.

PPT Master закреплён на Git commit в [runtime.py](skills/preza/scripts/runtime.py). Из корня этой копии:

```sh
/opt/homebrew/bin/python3.14 -B skills/setup/scripts/prepare_engine.py
/Library/Frameworks/Python.framework/Versions/3.12/bin/python3 -B skills/setup/scripts/prepare_engine.py
```

На других машинах используйте фактический путь выбранного Python. Скрипт размещает checkout в `~/.local/share/preza/engines/` и зависимости в `~/.local/share/preza/venvs/<версия>/`. Microsoft PowerPoint и Poppler обеспечивают рендер в PDF и PNG на macOS или Windows. Чистый профиль Codex обнаруживает движок без регистрации стороннего клиента.

## Команды для этапа тестирования

```sh
python -m unittest discover -s tests -v
python skills/setup/scripts/doctor.py --host codex --offline --json
python skills/preza/scripts/runtime.py --host codex --level "Обычный"
```

Используйте подготовленную venv для каждого интерпретатора. Приёмка включает Quick и стандартный экспорт, открытие PPTX в PowerPoint, редактирование элемента схемы, все PNG, проверку речи и заметок, квитанцию Orca и выборку памяти. Отдельный эксперимент сравнивает Astra high и xhigh по одинаковому брифу и перемешанным обезличенным рендерам. Оцените прочтение вывода, точность замечаний, пропуски, время и доступные данные о расходе. В эталонной паре до вскрытия разметки рецензенты не видят историю принятия. Для четырёх режимов сравните время и число обязательных дизайнерских правок после первой выдачи. Принятие фиксирует владелец.

При обслуживании отдельных блоков сохраняются встроенные проверки скриптов с флагом --selftest. Числа сверяются с реестром, речь — с заметками и DOCX. Для переходов и Morph проверяется показ и чистая копия. Подробные условия и форматы приведены в [приёмке](skills/preza/blocks/verify.md).
