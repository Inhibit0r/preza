# preza

Запустите preza из папки проекта и дайте тему, задание или лекции. Текущая сессия с выбранными вами моделью и глубиной рассуждения соберёт редактируемую презентацию PowerPoint через PPT Master. По материалам и предыдущим работам агент определит аудиторию и стиль. При необходимости уточнит длительность или число слайдов, уровень проработки и нужна ли речь. Если заказать речь, вы получите единый текст в Word и заметки к слайдам. Деление по выступающим можно попросить отдельно.

## Сценарий

[Основной навык](skills/preza/SKILL.md) управляет раскадровкой, обликом, нативной сборкой и проверкой. Дизайн новой темы выбирает агент. Серия использует свой DESIGN.md, спецификацию или принятую работу. [House rules](skills/deck-house-rules/SKILL.md) содержат критерии первой выдачи и пополняемые антипаттерны. [Контракт хостов](skills/preza/references/hosts.md) описывает доступные способы генерации изображений и независимой проверки. В Codex + Orca [профили](skills/preza/references/worker-profiles.json) задают модели и глубину работников. Папки сдачи, защита ручных правок и именование описаны в [регламенте хранения](skills/preza/references/layout.md).

| Уровень | Результат |
|---|---|
| Срочный | Quick Generate, одно направление, проверка фактов и рендеров, ключевой кадр по необходимости |
| Обычный | Авторский дизайн и редактируемая инфографика. Независимый критик проверяет раскадровку, затем рендер каждого содержательного слайда |
| Усиленный | Предварительная критика сложных схем и кадров, повторный рендер и проверка |
| Полный дизайн | Референсы, три направления с эскизами и отдельная финальная визуальная инспекция |

Начиная с Обычного, агент планирует иллюстрации для всей колоды. Их число зависит от раскадровки. В Codex для нужных кадров используется ImageGen, когда он доступен в сессии. Композицию и обрезку проверяют на готовом слайде.

Для движения предусмотрен отдельный [навык animate](skills/animate/SKILL.md). Он принимает тот же профиль хоста, что и основная сборка. Без анимации сдаётся обычная статическая колода. Для выбранного движения предусмотрен вариант без эффектов. Локальные решения и принятое владельцем оформление накапливаются в [памяти презентаций](skills/preza/references/memory.md).

## Первая выдача и повторная работа

Разбор слоёв, рекомендации по фотореалистичным кадрам, проверка стыков, соединителей и полноты шкал описаны в [визуальной композиции](skills/preza/references/visual-composition.md). Для Обычного и выше независимый визуальный разбор привязывается к контрольным суммам последних файлов. У каждого периода есть место на оси. Документированный пропуск остаётся пустым и получает объяснение в речи того же слайда. Рекомендация «проверить актуальность» относится к дате данных, отдельной от года публикации.

Для точечной правки готового PowerPoint приложите сам PPTX и укажите, какие слайды изменить. В PPT Master для этого есть [Edit Native PPTX](https://github.com/Inhibit0r/ppt-master/blob/1ab8a4df202677e442daebcc21931e33fbcc08df/skills/ppt-master/workflows/edit-native-pptx.md). При возврате к сданной работе preza сверяет файл с контрольной суммой в `PLAN.md`. Если вы правили его в PowerPoint, агент уточнит, продолжать ли в этом PPTX или перенести ваши изменения в исходники.

## Установка и сборочное окружение

| Среда | Установка и вход |
|---|---|
| Codex | В терминале выполните `codex plugin marketplace add Inhibit0r/preza --ref main`, затем `codex plugin add preza@preza`. В новом сеансе вызовите `$preza:setup`. Для работы дайте задание, например `$preza:preza Сделай доклад на 6 минут по приложенной лекции`. Для оформления и анимации доступны `$preza:deck-house-rules` и `$preza:animate`. |
| Claude Code | `claude plugin marketplace add Inhibit0r/preza`, затем `claude plugin install preza@preza`. В новом сеансе или после `/reload-plugins` доступны `/preza:setup`, `/preza:preza` и `/preza:deck-house-rules`. Историческая запись `ppt-master@preza` остаётся в маркетплейсе и подхватывается при наличии, если закреплённый движок ещё не подготовлен. |
| Другой агент | Возьмите полную копию репозитория нужной версии. Передайте текущему агенту абсолютные пути [preza](skills/preza/SKILL.md), [setup](skills/setup/SKILL.md) и [deck-house-rules](skills/deck-house-rules/SKILL.md). Скажите: «Прочитай эти инструкции из копии preza, используй профиль manual, собери презентацию по этому брифу в указанной папке». Скопируйте весь пакет с VERSION и соседними навыками, если переносите его. |

В переносимом стеке используйте его штатный установщик. Для проверки локального кандидата передайте нативному маркетплейсу путь к копии репозитория вместо удалённого источника. Версия пакета хранится в [VERSION](VERSION), её зеркалируют нативные манифесты.

Один и тот же setup готовит закреплённый checkout PPT Master и Python для всех хостов. Из корня пакета запустите:

```sh
python3 -X utf8 skills/setup/scripts/prepare_engine.py
python3 -X utf8 skills/setup/scripts/doctor.py --host manual --offline --json
python3 -X utf8 skills/preza/scripts/runtime.py --host manual --level "Обычный"
```

Укажите фактический профиль `claude` или `codex` в нативном сеансе. В Windows используйте `python`, если `python3` недоступен. Для отдельной установки задайте переменную окружения `PREZA_DATA_DIR` абсолютным путём, например `export PREZA_DATA_DIR="$PWD/.preza-selftest"` в sh или `$env:PREZA_DATA_DIR = Join-Path $PWD '.preza-selftest'` в PowerShell. Повторный запуск с тем же каталогом использует тот же checkout и venv. В обычной установке данные находятся в `~/.local/share/preza`. Директории `engines/`, `venvs/` и `memory/` находятся внутри каталога данных. `PREZA_MEMORY` и `PREZA_PPT_MASTER` явно задают другой путь с приоритетом над ним.

Для ручного входа достаточно доступа к файлам, Python, Git и установленным зависимостям. Нативный рендер итогового PPTX использует Microsoft PowerPoint на macOS или Windows и Poppler. Генерация изображений, доступ к источникам и независимое ревью зависят от возможностей выбранного сеанса и разрешений владельца. Если отдельный критик не смог открыть финальные слайды, статус независимой проверки остаётся открытым. Сценарий с пользовательскими материалами и редактируемой графикой работает без сервиса генерации.

## Команды для этапа тестирования

Запускайте проверки из корня пакета в подготовленном окружении Python 3.12 или 3.14.

```sh
python -X utf8 -m unittest discover -s tests -v
python -X utf8 skills/setup/scripts/doctor.py --host codex --offline --json
python -X utf8 skills/preza/scripts/runtime.py --host codex --level "Обычный"
```

Приёмка включает Quick и стандартный экспорт, открытие PPTX в PowerPoint, редактирование элемента схемы, все PNG, проверку заказанной речи и заметок, свидетельство отдельного рецензента (в Orca — его квитанцию) и выборку памяти. В Codex по запросу отдельный эксперимент сравнивает Astra high и xhigh по одинаковому брифу и перемешанным обезличенным рендерам. Оцените прочтение вывода, точность замечаний, пропуски, время и доступные данные о расходе. В эталонной паре до вскрытия разметки рецензенты не видят историю принятия. Для четырёх режимов сравните время и число обязательных дизайнерских правок после первой выдачи. Принятие фиксирует владелец.

При обслуживании отдельных блоков сохраняются встроенные проверки скриптов с флагом --selftest. Числа сверяются с реестром, речь — с заметками и DOCX. Для переходов и Morph проверяется показ и чистая копия. Подробные условия и форматы приведены в [приёмке](skills/preza/blocks/verify.md).
