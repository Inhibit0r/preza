# preza: animate

Оживляет уже собранный проект по блоку [Движение](../preza/blocks/motion.md). Внутри маршрута `/preza:preza` тот же блок включается сам; этот вход — для проекта, который уже собран.

Навык запускается только по команде пользователя. Перед работой разреши фактический хост и роли по [hosts.md](../preza/references/hosts.md); окружение запиши после шага 1, когда папка задания найдена: `runtime.py --write <папка задания>/Исходники/runtime.json` (старая плоская работа — `runtime.json` в её корне). В Claude используй доступный Skill tool, в Codex читай SKILL.md; вызовы HUD не имитируются.

1. Найди проект ppt-master: путь из запроса, иначе `scripts/scaffold.py find` навыка preza → папка задания (запуск из папки предмета — серия и задание из запроса по списку `series` в ответе `find`; не названы или не найдены — спроси одним вопросом, новых папок не создавай), проект — единственная папка в её `Исходники/4-сборка/` (старая плоская работа — путь в её `PLAN.md`); нужны `svg_output/` и `design_spec.md`. Анимация пишется в нативный PPTX из `svg_output/` — без проекта ppt-master скажи об этом и остановись; проект Срочного (Quick Generate) `design_spec.md` не имеет — предложи переходы флагами экспорта или пересборку колоды на Обычном и остановись.
   Готово, когда путь проекта записан в `PLAN.md`. Уровень проработки берётся из строки «Уровень: …» в шапке PLAN.md, нет её — Обычный: от него зависит ревью брифа.
2. Загрузи PPT Master способом текущего хоста по разрешённому пути и объяви применение. Независимое ревью брифа по уровню проработки (таблица SKILL.md preza) — по [hosts.md](../preza/references/hosts.md), «Независимое ревью».
3. Пройди [Движение](../preza/blocks/motion.md) целиком. Промежуточные слайды из брифа дорисуй в `svg_output/` по правилам ppt-master и прогони его финальную проверку качества до разметки. Затем — шаг «Движение» из [Проверки](../preza/blocks/verify.md) и сдача по её шагу 7: до копирования — «Возврат к сданной работе» (SKILL.md preza, §3) для уже сданного файла и правило «Имя занято» ([layout.md](../preza/references/layout.md)); показ (и чистая версия, если её просили) — в корень папки задания, sha256 каждого — в `PLAN.md`.
   Готово, когда показ (и чистая версия, если её просили) экспортирован и проверен.
