# preza: animate

Оживляет уже собранный проект по блоку [Движение](../preza/blocks/motion.md). Внутри маршрута `/preza:preza` тот же блок включается сам; этот вход — для проекта, который уже собран.

Навык запускается только по команде пользователя. Команда раскрыла его текст, но строка состояния засчитывает только вызов `Skill` — первым действием вызови `Skill(preza:animate)`: навык загрузится, HUD его покажет, дальше выполняй этот текст. В Codex этого шага нет.

1. Найди проект ppt-master: путь из запроса или из `PLAN.md` текущей папки; нужны `svg_output/` и `design_spec.md`. Анимация пишется в нативный PPTX из `svg_output/` — без проекта ppt-master скажи об этом и остановись.
   Готово, когда путь проекта записан в `PLAN.md`. Важность берётся оттуда же, нет её — обычная: от неё зависит ревью брифа.
2. Загрузи `ppt-master:ppt-master` через `Skill` и объяви строкой `▎ Подключаю: ppt-master:ppt-master — разметка анимации и экспорт`. Ревью брифа по важности — ещё `claudex-loop`.
3. Пройди [Движение](../preza/blocks/motion.md) целиком. Промежуточные слайды из брифа дорисуй в `svg_output/` по правилам ppt-master и прогони его финальную проверку качества до разметки. Затем — шаг «Движение» из [Проверки](../preza/blocks/verify.md).
   Готово, когда показ (и чистая версия, если её просили) экспортирован и проверен.
