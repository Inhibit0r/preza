# preza: setup

1. Запусти `scripts/doctor.py --json` из папки этого навыка (`python3`, на Windows — `python`). Покажи пользователю таблицу по группам «Ядро» и «По блокам»: компонент, есть или нет, подробность. Затем список обновлений.
2. Обязательное («Ядро») на месте и обновлений нет — скажи об этом и закончи.
3. Иначе спроси одним вызовом AskUserQuestion с множественным выбором, что установить или обновить: пункт на каждый недостающий компонент и каждое обновление, обязательные первыми. Для выбранного выполняй команды из `fix` по одной и показывай вывод.
4. Пункты `manual` — вход в Codex, установка PowerPoint, ключи API — показывай инструкцией: их делает пользователь. Команду входа предложи набрать в Claude Code с префиксом `!`, например `! codex login`.
5. После установки плагинов попроси выполнить `/reload-plugins` и запусти `doctor.py` снова.

Готово, когда повторный запуск не показывает недостающего в «Ядре» или пользователь отказался от оставшихся пунктов.
