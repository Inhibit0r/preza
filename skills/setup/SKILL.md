# preza: setup

1. Определи текущий хост по [правилам окружения](../preza/references/hosts.md). Выполни scripts/doctor.py --host <claude|codex> --json из папки этого навыка, найденным Python с -X utf8. Покажи ядро, компоненты блоков и обновления; различай файлы/регистрации и рабочую функцию.
2. Ядро на месте — проверь фактические инструменты, которые нужны выбранному маршруту: поиск, вход Codex и imagegen для картинок; рецензент — субагент текущей сессии (doubt-driven-development необязателен). Для уровня Срочный в Claude — доступен ли инструмент Workflow (нет — параллельные ветки идут фоновыми субагентами). Для речи — навык `antiplagiat`: без него речь сдаётся с явной пометкой «antiplagiat не выполнен». Строка «синхронизация форка ppt-master» показывает дату последнего успешного прогона: старше 14 дней или workflow выключен — `gh workflow enable sync-upstream.yml --repo Inhibit0r/ppt-master`; «синхронизация остановлена: issue …» — конфликт или красный контракт, порядок восстановления — `tools/README.md` форка. «не проверено» — нет `gh` или GitHub не ответил: повтори позже, ядро это не блокирует. Doctor проверяет метаданные; он не обещает OAuth, картинки или выполненное ревью за другой процесс.
3. Если пользователь уже разрешил настройку, выполни нужные обратимые установки и исправления. Иначе предложи недостающие компоненты одним инструментом вопросов. Установки выполняются с учётом локального обработчика стека; секреты остаются на машине.
4. Вход и системные разрешения потребуются только при конкретном сбое; покажи соответствующий штатный login. Не копируй OAuth между клиентами. Переносить плагины и настройки другого хоста целиком для исправления диагностики не требуется.
5. ppt-master ставится и обновляется из маркетплейса preza (`ppt-master@preza`, форк с указателями на правила): `claude plugin marketplace update preza`, `claude plugin update ppt-master@preza`. Старый `ppt-master@ppt-master` doctor отмечает (на хосте Claude — в ядре, на хосте Codex — среди блоков с командами для Claude Code); на машине со стеком `~/.agents/stack` установки идут через его install.py. Claude обновляет загрузку через /reload-plugins, Codex — новым сеансом.
6. Повтори doctor для того же хоста и нужные функциональные проверки. Готово, когда обязательное ядро проходит, запрошенные функции проверены или конкретное ограничение явно принято пользователем.
