# preza: setup

1. Определи текущий хост по [правилам окружения](../preza/references/hosts.md). Выполни scripts/doctor.py --host <claude|codex> --json из папки этого навыка, найденным Python с -X utf8. Покажи ядро, компоненты блоков и обновления; различай файлы/регистрации и рабочую функцию.
2. Ядро на месте — проверь фактические инструменты, которые нужны выбранному маршруту: поиск, imagegen, авторизацию независимого рецензента. Doctor проверяет метаданные; он не обещает OAuth, картинки или выполненное ревью за другой процесс.
3. Если пользователь уже разрешил настройку, выполни нужные обратимые установки и исправления. Иначе предложи недостающие компоненты одним инструментом вопросов. Установки выполняются с учётом локального обработчика стека; секреты остаются на машине.
4. Вход и системные разрешения потребуются только при конкретном сбое; покажи соответствующий штатный login. Не копируй OAuth между клиентами. Переносить плагины и настройки другого хоста целиком для исправления диагностики не требуется.
5. После обновления Preza/PPT Master запусти ../deck-house-rules/scripts/patch_ppt_master.py для зарегистрированного корня PPT Master. Он сохраняет атрибуцию и локальные правила. Claude обновляет загрузку через /reload-plugins, Codex — новым сеансом.
6. Повтори doctor для того же хоста и нужные функциональные проверки. Готово, когда обязательное ядро проходит, запрошенные функции проверены или конкретное ограничение явно принято пользователем.
