# Хост и начальное окружение

Хост — текущая пользовательская сессия. Установленные CLI, папка плагина и названия моделей его не определяют.

| Возможность | Ведущий Claude Code | Ведущий Codex |
|---|---|---|
| Вводная, план, текст, SVG, решения | текущая сессия Claude | текущая сессия Codex |
| Независимое ревью | Codex через claudex-loop, `--host claude` | Claude через claudex-loop, `--host codex` |
| Загрузка навыка | настоящий `Skill`, если он доступен | чтение SKILL.md по разрешённому пути |
| Вопросы | доступный инструмент вопросов Claude | доступный инструмент вопросов Codex |
| Иллюстрации | передача в сессию Codex с imagegen | текущий imagegen, если инструмент доступен; иначе передача в способную сессию Codex |
| Делегирование | инструмент и модели текущего хоста | инструмент и модели текущего хоста |

Сохраняй модель ведущей сессии. Рецензент наследует настройки своего CLI, если пользователь не выбрал модель явно; фиксированные `sonnet`/модели Codex сюда не переносятся. Перед вызовом прочитай claudex-loop и запиши запрос модели и наблюдаемую модель отдельно. При недоступном рецензенте покажи конкретный сбой; замена на ведущего не считается независимым ревью.

## Разрешение окружения

До раскадровки выполни `scripts/runtime.py --host codex` или `--host claude` из папки навыка, исходя из фактического хоста. Без флага скрипт принимает только однозначный CODEX_THREAD_ID или CLAUDECODE; при конфликте унаследованных маркеров останавливается. Запиши JSON в `<проект>/runtime.json`, роли и ограничения — в PLAN.md. При продолжении проверь, что хост тот же; смена хоста явно перестраивает роли и требует проверки зависимостей нового маршрута.

`ppt_master` и `claudex_runner` — абсолютные пути к текущим файлам. Зарегистрированные файлы Claude-плагина разрешено читать из Codex; это не создаёт у Codex инструмент Skill или plugin namespace. Источник отсутствует — настрой переносимый навык или плагин, затем повтори проверку. Соседний файл плагина не загружай под выдуманным slash-именем.

`doctor.py --host <хост> --offline --json` проверяет ядро и регистрации активного хоста. Регистрация MCP, наличие SKILL.md и наличие CLI не доказывают авторизацию или выполнение функции. Поиск, imagegen и нужные инструменты подтверждай фактическим каталогом и вызовом текущей сессии. OAuth и ключи другой сессии с Markdown не переносятся.

## Исполнение

Python-команды выполняй найденным Python с `-X utf8` (на Windows обычно `python`, на macOS — `python3`). Рендер обоих хостов: `python -X utf8 scripts/render_pptx.py <deck.pptx> <новая_папка_раунда>`; macOS вызывает существующий AppleScript-рендер, Windows — PowerPoint COM и Poppler. Каждый PNG осматривается независимо от успешного кода выхода.

Параллельные оси и пачки страниц раздавай только при разрешённом делегировании и наличии подходящего инструмента. Иначе хост выполняет те же оси/пачки последовательно и сохраняет те же отчёты; роль независимого рецензента этим не заменяется. Уже разрешённые действия и заданный бриф выполняй без повторного подтверждения. Неразрешённые выборы содержания и оформления остаются у пользователя.

Навыки, вызовы MCP и делегирование объявляй по факту. Claude HUD учитывает настоящий Skill tool; чтение файлов в Codex — загрузка инструкции, но не вызов Skill или доказательство работы навыка.
