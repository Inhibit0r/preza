# Хост и начальное окружение

Хост — текущая пользовательская сессия. Установленные CLI, папка плагина и названия моделей его не определяют.

| Возможность | Ведущий Claude Code | Ведущий Codex |
|---|---|---|
| Вводная, план, текст, SVG, решения | текущая сессия Claude | текущая сессия Codex |
| Независимое ревью | свежий субагент Claude (Agent) | свежий субагент Codex; без субагентов — новый `codex exec` |
| Загрузка навыка | настоящий `Skill`, если он доступен | чтение SKILL.md по разрешённому пути |
| Вопросы | доступный инструмент вопросов Claude | доступный инструмент вопросов Codex |
| Иллюстрации | `codex exec` с `$imagegen` (раздел «Картинки») | встроенный imagegen; без него — `codex exec` с `$imagegen` |
| Делегирование | инструмент и модели текущего хоста | инструмент и модели текущего хоста |

Сохраняй модель ведущей сессии.

## Независимое ревью

Рецензент — свежий субагент текущего хоста: он видит только ARTIFACT (проверяемый файл с абсолютными путями PNG) и CONTRACT (критерии готовности блока), без рассуждений ведущего. Если навык doubt-driven-development установлен, загрузи его и веди цикл по нему. Иначе передай субагенту этот промпт:

> Состязательное ревью. Найди, что не так с артефактом; считай автора самоуверенным. Ищи невысказанные допущения, неразобранные случаи, нарушения контракта и расхождения с соглашениями. Находки или явное «после тщательной проверки проблем не нашёл». Последняя строка — APPROVED или REVISE.
> ARTIFACT: <пути> · CONTRACT: <критерии>

Модель рецензента: в Claude — sonnet; opus для Усиленного и Полного дизайна и для раунда после REVISE. В Codex — модель хоста по умолчанию. Хост Codex без субагентов запускает свежий процесс с тем же промптом в prompt.md: `codex exec --skip-git-repo-check -s read-only - < prompt.md` (macOS, Git Bash); PowerShell 7 — `Get-Content prompt.md -Raw | codex exec --skip-git-repo-check -s read-only -` (в Windows PowerShell 5.1 кириллица в канале портится). Промпт приходит через stdin один раз: второе перенаправление его затрёт. Число раундов — по таблице SKILL.md §2. REVISE и сбой рецензента — не одобрение: решения по находкам записываются в `5-проверка/review-log.md`, неразрешённые существенные находки сообщаются пользователю до перехода дальше; в работе без пользователя (SKILL.md §3) — в итог, работа идёт дальше. Ведущий сам себя не рецензирует: недоступный субагент — это названный сбой.

## Картинки

Хост Claude генерирует картинки процессом Codex из основной сессии (фоновые агенты не получат разрешение на запуск):

```bash
codex exec --skip-git-repo-check -s workspace-write -C "<папка задания>/Исходники/4-сборка/<проект>/images" '$imagegen <промпт>. <абзац качества>. Сохрани результат в текущую папку как <имя>.png и выведи абсолютный путь к файлу последней строкой.' < /dev/null
```

Одинарные кавычки обязательны: в двойных оболочка подставит пустую переменную вместо `$imagegen`. Путь к картинке — последняя строка вывода; размер проверь (`sips -g pixelWidth -g pixelHeight` на macOS). Одна картинка — около полутора минут, поэтому независимые картинки запускай фоновыми процессами, до трёх одновременно. Хост Codex использует встроенный imagegen, если он есть в сессии, иначе ту же команду.

Промпт собирается по правилу [deck-house-rules](../../deck-house-rules/SKILL.md) §1 «Без генеративного слопа» — перечитай его перед каждой пачкой генерации. Абзац качества идёт в каждый вызов после промпта — так правило доходит до генератора:

```
Quality: no generative-AI look — no glowing lines or networks, no holograms or wireframes, no neon, glow, lens flare or starbursts, no perfect symmetry or cloned objects, no plastic CGI surfaces. Strict: NO text, NO letters, NO numbers, NO watermarks.
```

Режим «снимок» дописывает `A real photograph: physical scene, natural imperfections, every object rests on a surface with a soft contact shadow, NO floating objects.`, режим «стилистика» — `Keep exactly this deck style: <описание манеры из плана>.` Апостроф внутри одинарных кавычек команды замени на ’.

## Разрешение окружения

До раскадровки выполни `scripts/runtime.py --host codex` или `--host claude` из папки навыка, исходя из фактического хоста. Без флага скрипт принимает только однозначный CODEX_THREAD_ID или CLAUDECODE; при конфликте унаследованных маркеров останавливается. Запиши его в файл: `runtime.py --host <хост> --write <папка задания>/Исходники/runtime.json` (старая плоская работа — `runtime.json` в её корне); роли и ограничения — в PLAN.md. При продолжении проверь, что хост тот же; смена хоста явно перестраивает роли и требует проверки зависимостей нового маршрута.

`ppt_master`, `deck_house_rules` и `review_skill_path` — абсолютные пути к текущим файлам; переменная `PREZA_PPT_MASTER` указывает ppt-master явно (клон форка при разработке). В начале каждой сессии по работе повтори `scaffold.py work <папка задания>` и `runtime.py … --write …`: путь `ppt_master` меняется с версией, пути папок — после переименований. Зарегистрированные файлы Claude-плагина разрешено читать из Codex; это не создаёт у Codex инструмент Skill или plugin namespace. Источник отсутствует — настрой переносимый навык или плагин, затем повтори проверку. Соседний файл плагина не загружай под выдуманным slash-именем.

`doctor.py --host <хост> --offline --json` проверяет ядро и регистрации активного хоста. Регистрация MCP, наличие SKILL.md и наличие CLI не доказывают авторизацию или выполнение функции. Поиск, imagegen и нужные инструменты подтверждай фактическим каталогом и вызовом текущей сессии. OAuth и ключи другой сессии с Markdown не переносятся.

## Исполнение

Python-команды выполняй найденным Python с `-X utf8` (на Windows обычно `python`, на macOS — `python3`). Рендер обоих хостов: `python -X utf8 scripts/render_pptx.py <deck.pptx> <новая_папка_раунда>`; macOS вызывает существующий AppleScript-рендер, Windows — PowerPoint COM и Poppler. Каждый PNG осматривается независимо от успешного кода выхода.

Параллельные оси и пачки страниц раздавай при разрешённом делегировании и наличии подходящего инструмента; иначе хост выполняет их последовательно с теми же отчётами. Последовательное выполнение хостом не заменяет независимого рецензента. Уже разрешённые действия и заданный бриф выполняй без повторного подтверждения. Неразрешённые выборы содержания и оформления остаются у пользователя.

Навыки, вызовы MCP и делегирование объявляй по факту. Claude HUD учитывает настоящий Skill tool; чтение файлов в Codex — загрузка инструкции, но не вызов Skill или доказательство работы навыка.
