# Сборка

1. Загрузи навык `ppt-master:ppt-master` и веди Generate по его процессу. Проект ppt-master создавай по явному пути внутри папки проекта.
2. Данные — нативные графики и таблицы по шаблонам `templates/charts` и `templates/tables`; для графиков пройди стадию `verify-charts`. В группе нативного графика — только данные; панель и подписи стоят рядом отдельными объектами. Стиль подписей значений задавай в метаданных графика.
3. Цвет гиперссылок задай в теме (`hlink`) под палитру.
4. Речь в маршруте → заметки докладчика берутся из `script.md`.
5. Проверка качества ppt-master → `finalize_svg` → экспорт `svg_to_pptx.py --native-charts-and-tables`. Путь экспорта раунда записывай в `PLAN.md`.
6. `finalize_svg` идёт несколько минут: правки собирай пачкой и пересобирай один раз.

Готово, когда проверка качества ppt-master пройдена и PPTX экспортирован.
