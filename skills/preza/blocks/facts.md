# Факты

1. Разложи тему на 2–4 независимые оси — вопросы доклада, которые исследуются без общего состояния. На каждую ось — субагент на дешёвой модели (например, `sonnet`); все вызовы — в одном сообщении, чтобы шли параллельно (порядок навыка `superpowers-dispatching-parallel-agents`, если он установлен). Задание самодостаточное:
   - ось и её вопросы;
   - правило поиска из SKILL.md («В любом маршруте») дословно;
   - первичные источники, где они есть: отчёты компании, регуляторы, официальная статистика, отраслевые ассоциации;
   - результат — только файл `research/<ось>.md`: таблица «показатель | значение | ед. | период | URL | цитата | первичный/вторичный» и раздел «Пробелы и противоречия»;
   - исчерпан лимит поиска (ответы 402, 429, 432) — остановиться и сообщить; смена ключа — решение пользователя.
2. Сведи результаты осей: проверь ключевые числа сам (URL открывается, цитата совпадает), разбери противоречия между осями.
3. Показатель, который источник перестал раскрывать, замещай независимыми данными (международная статистика, отчёты конкурентов, индексы цен) и называй замену в речи.
4. Расчёты — `data/calc.py`: каждое производное число считается из данных под `assert`, результат — `data/metrics.json`.
5. Реестр:
   - `data/sources.md` — таблица `| id | Документ | URL | Что берём |`;
   - `data/claims.csv` — `id;value;unit;period;source;context;claim`; `source` — id из `sources.md` или `calc:<ключ>` из `metrics.json`; `context` — регулярное выражение слов, которые стоят рядом с числом в речи;
   - `data/usage.csv` — `slide;claims` (id через запятую, `SKIP` для слайда источников) — заполняется в Истории;
   - скопируй `scripts/check_numbers.py` в `data/`.

Готово, когда каждое число для слайдов и речи есть в `claims.csv` с URL и цитатой и `calc.py` проходит.
