# Факты

1. Разложи тему на 2–4 независимые оси — вопросы доклада, которые исследуются без общего состояния. При доступном и разрешённом делегировании назначь оси роли research по [протоколу хоста](../references/hosts.md); иначе выполни их последовательно с теми же файлами результата. Задание самодостаточное:
   - ось и её вопросы;
   - разрешённую последовательность поиска из references/hosts.md;
   - первичные источники, где они есть: отчёты компании, регуляторы, официальная статистика, отраслевые ассоциации;
   - результат — только файл `2-материалы/research/<ось>.md`: таблица «показатель | значение | ед. | период | URL | цитата | первичный/вторичный» и раздел «Пробелы и противоречия»;
   - исчерпан лимит поиска (402, 429, 432) — выполнить действующую локальную политику ключей и резервного поиска; при отсутствии разрешённого пути сообщить конкретный сбой.
Для временного ряда зафиксируй начало, конец, частоту, единицы, географию и совокупность. Включи каждый календарный период в реестр. Для наблюдения укажи число и источник, для пропуска — пустое значение и проверенные выпуски или таблицы. Проверь свежесть по дате наблюдения, методику и базу каждого выпуска. При редизайне используй сохранённые материалы; новый поиск допустим в согласованном объёме. Пересчёт из прямо опубликованного изменения пометь как расчёт, укажи точность и формулу. Сначала ищи сопоставимое значение в разрешённых материалах. Если его нет, сохрани шаг оси и оставь разрыв на графике. В речи к этому слайду назови периоды и подтверждённую причину. Если причина неизвестна, достаточно точной фразы «В доступных выпусках за эти годы показатель не приведён. Источник причины не поясняет». Упоминай COVID-19, остановку опроса или изменение методики только при прямом подтверждении источником. Число 0 означает измеренный ноль. Интерполяция, выдуманная причина и пропуск имеющихся наблюдений ради дизайна недопустимы. Изменение заданного периода или показателя согласуй с владельцем.

2. Сведи результаты осей: проверь ключевые числа сам (URL открывается, цитата совпадает), разбери противоречия между осями.
3. Если выпуск перестал раскрывать показатель, проверь сопоставимость другого источника по определению, охвату и единицам. Показатель с другим знаменателем требует отдельного ряда.
4. Расчёты — `2-материалы/data/calc.py`: каждое производное число считается из данных под `assert`, результат — `2-материалы/data/metrics.json`.
5. Реестр:
   - `2-материалы/data/sources.md` — таблица `| id | Документ | URL | Что берём |`;
   - `2-материалы/data/claims.csv` — `id;value;unit;period;source;context;claim`; `source` — id из `sources.md` или `calc:<ключ>` из `metrics.json`; `context` — регулярное выражение слов, которые стоят рядом с числом в речи;
   - `2-материалы/data/usage.csv` — `slide;claims` (id через запятую, `SKIP` для слайда источников) — заполняется в Истории;
   - скопируй `scripts/check_numbers.py` в `2-материалы/data/`.

Готово, когда каждое число для слайдов и речи есть в `claims.csv` с URL и цитатой и `calc.py` проходит.
