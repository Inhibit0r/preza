# Факты

1. Разложи тему на 2–4 независимые оси — вопросы доклада, которые исследуются без общего состояния. При доступном и разрешённом делегировании раздай оси параллельно на модели текущего хоста по hosts.md; иначе выполни их последовательно с теми же файлами результата. Задание самодостаточное:
   - ось и её вопросы;
   - правило поиска из SKILL.md §3 («Интернет: Tavily → Firecrawl → Agent-Reach») дословно;
   - первичные источники, где они есть: отчёты компании, регуляторы, официальная статистика, отраслевые ассоциации;
   - результат — только файл `2-материалы/research/<ось>.md`: таблица «показатель | значение | ед. | период | URL | цитата | первичный/вторичный» и раздел «Пробелы и противоречия»;
   - исчерпан лимит поиска (402, 429, 432) — выполнить действующую локальную политику ключей и резервного поиска; при отсутствии разрешённого пути сообщить конкретный сбой.
2. Сведи результаты осей: проверь ключевые числа сам (URL открывается, цитата совпадает), разбери противоречия между осями.
3. Показатель, который источник перестал раскрывать, замещай независимыми данными (международная статистика, отчёты конкурентов, индексы цен) и называй замену в речи.
4. Расчёты — `2-материалы/data/calc.py`: каждое производное число считается из данных под `assert`, результат — `2-материалы/data/metrics.json`.
5. Реестр:
   - `2-материалы/data/sources.md` — таблица `| id | Документ | URL | Что берём |`;
   - `2-материалы/data/claims.csv` — `id;value;unit;period;source;context;claim`; `source` — id из `sources.md` или `calc:<ключ>` из `metrics.json`; `context` — регулярное выражение слов, которые стоят рядом с числом в речи;
   - `2-материалы/data/usage.csv` — `slide;claims` (id через запятую, `SKIP` для слайда источников) — заполняется в Истории;
   - скопируй `scripts/check_numbers.py` в `2-материалы/data/`.

Готово, когда каждое число для слайдов и речи есть в `claims.csv` с URL и цитатой и `calc.py` проходит.
