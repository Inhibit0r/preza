# Материалы

1. Переведи файлы в текст: to-md, если установлен, или pandoc. Страницы PDF без текстового слоя и слайды-картинки читай как изображения.
2. Выжимка — `notes/materials.md`: тезисы, числа, цитаты, у каждого файл и страница; отдельным разделом — пробелы.
3. Пробелы, которым нужны внешние факты, закрой блоком [Факты](facts.md) только по ним. Числа из материалов, которые пойдут на слайды, внеси в реестр с источником «файл, стр.» (формат — facts.md, шаг 5).

Готово, когда каждый тезис для раскадровки привязан к файлу и странице или помечен как позиция пользователя.
