# История

1. Раскадровка в `PLAN.md`, раздел `## Раскадровка`: таблица `| № | заголовок-вывод | что видит зритель | главное число или объект | источник (id) | время, с |`. Заголовок — вывод («Двое держат половину рынка»), тема идёт в подзаголовок. Один слайд — одна мысль.
2. Структура вытекает из аргумента: с чем слушатель приходит и что понимает к концу. Хронометраж — около 140 слов речи в минуту; для доклада с данными ориентир — два слайда в минуту, для концептуального — меньше.
3. Факты в маршруте → заполни `data/usage.csv` по раскадровке и запусти `python3 data/check_numbers.py`.
4. Речь в маршруте → черновик по [speech.md](speech.md), раздел «Черновик».
5. Ревью по важности (таблица в SKILL.md). Решения по замечаниям — в `notes/review-log.md`: принято, отклонено, почему.
6. ✅ Покажи пользователю раскадровку и черновик речи.

Готово, когда пользователь утвердил раскадровку.
