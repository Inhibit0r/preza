# Облик

1. Три направления — из смысла темы, из брифа референсов или внутри фирменного стиля. В каждом: визуальная метафора, настроение, палитра с ролями цветов, пара шрифтов, приём с картинками. На каждое — эскиз через Codex `$imagegen` по [deck-house-rules](../../deck-house-rules/SKILL.md) §1.
2. ✅ Пользователь выбирает направление или смешивает их.
3. Шрифты — из комплекта Office с кириллицей, которые есть на компьютере показа (Century Gothic, Calibri, Arial, Georgia, Cambria); место показа неизвестно — спроси.
4. Выбранное впиши в `design_spec.md` и `spec_lock.md` ppt-master (§I–VI: стиль, палитра, типографика, сетка, иконки) и в `page_rhythm` — чередование плотных и «дышащих» слайдов. Мелкий текст на полупрозрачных панелях — светлые оттенки палитры.
5. План картинок для всех слайдов → ревью Codex → генерация `$imagegen` → осмотр каждой (deck-house-rules §1).

Готово, когда направление выбрано, спецификации заполнены и каждая картинка из плана осмотрена.
