# Правила оформления презентаций

Действуют для любой презентации, которая собирается в PPTX. ppt-master ссылается на этот файл из своих `SKILL.md`, `references/image-generator.md` и `references/executor-base.md` (вставляет `scripts/patch_ppt_master.py`).

## 1. Картинки для слайдов — через claudex-loop и Codex `$imagegen`

Относится к фонам, иллюстрациям, текстурам и картинкам-инфографике. Графики и таблицы с данными — нативные объекты PowerPoint, их не генерируют.

1. **План (хост).** Для каждой картинки: слайд и назначение; композиция и свободная зона под текст; размер (для 16:9 — 1672×940 или 1920×1080); палитра проекта как указание к цвету; «без текста, букв, цифр и водяных знаков» — кириллица в генерации ненадёжна, весь текст остаётся редактируемым в PPTX. Для ppt-master план — строки `Acquire Via: ai` и `images/image_prompts.json`.
2. **Независимое ревью плана** — противоположный провайдер по claudex-loop с фактическим host (только чтение): Codex при ведущем Claude, Claude при ведущем Codex. Используй роли из [hosts.md](../preza/references/hosts.md).
3. **Генерация — Codex `$imagegen`**. При ведущем Codex используй фактически доступный встроенный image_gen. При ведущем Claude или Codex CLI без этого инструмента передай план в способную сессию Codex; установленный SKILL.md не доказывает наличие генератора. CLI-путь с OPENAI_API_KEY — только с согласия пользователя. Файл, возвращённый генератором, скопируй в images проекта и запиши происхождение; не угадывай его каталог.
4. **Инспекция.** Хост открывает каждую картинку: нет текста и артефактов, палитра совпадает, фокус не попадает под текст. После сборки осматривается рендер PowerPoint; независимое ревью назначается противоположному провайдеру по важности.

Хост не рисует растровые картинки сам и не подменяет `$imagegen` другим генератором без согласия пользователя.

## 2. Антипаттерны оформления

| Антипаттерн | Почему плохо | Как делать |
|---|---|---|
| Подсветка числа, метки или заголовка овальным свечением (эллипс с `radialGradient` / glow под элементом) | в PowerPoint виден край овала, пятно выглядит мутным и снижает контраст текста | встроенные фигуры PowerPoint: скруглённый прямоугольник или «таблетка» с рамкой акцентного цвета 1–1,5 pt без заливки (или с заливкой не больше 10%), акцентная черта под элементом, акцентный цвет и кегль самого числа |
| Эллипс-подложка с радиальным градиентом под заголовком ради контраста | тот же видимый овал, выход за холст | прямоугольник с линейным градиентом вдоль края слайда или затемнение самой картинки фона |

## 3. После обновления ppt-master

`claude plugin update` перезаписывает кэш плагина и убирает указатели. Вернуть их — скриптом из папки этого навыка:

```bash
python3 <папка навыка deck-house-rules>/scripts/patch_ppt_master.py
```

Скрипт идемпотентен и после вставки запускает `attribution_guard.py` ppt-master; ненулевой код — указатели не вставлены или защита плагина не прошла.
